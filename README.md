# 🎬 Data Visualization Hub

A Netflix Data Visualization Dashboard built with **Streamlit**, **Pandas** & **Plotly**.

## Features
- 📊 Interactive charts (pie, bar, area, histogram)
- 🔍 Filterable dashboard by Type, Region, Rating, Year, Category
- 📈 Revenue analytics by region and subscription plan
- 🔎 Searchable data explorer with pagination
- 📱 Fully responsive design
- 📤 Upload your own CSV dataset

## Tech Stack
- **Streamlit** - Web framework
- **Pandas** - Data processing
- **Plotly** - Interactive visualizations

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
